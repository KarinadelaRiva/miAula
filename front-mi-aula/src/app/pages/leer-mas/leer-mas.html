Proyecto de tesis universitaria

Mi Aula

Una aplicación pensada para centralizar la gestión de aulas, reservas y solicitudes en un mismo lugar, con una experiencia clara para estudiantes, docentes y administradores.

Volver al inicio Ingresar al sistema
Para qué sirve

Organizar el uso de espacios

Mi Aula permite consultar disponibilidad, solicitar reservas y administrar espacios de forma ordenada, reduciendo tareas manuales y evitando superposiciones.

Ventajas

Más control y menos fricción

  • Consulta rápida de disponibilidad y reservas.
  • Flujo de solicitud más simple para los usuarios.
  • Administración centralizada para seguimiento y aprobación.
Contexto académico

Desarrollado como tesis universitaria

Este proyecto forma parte de una tesis universitaria orientada a resolver una necesidad real en el ámbito académico, aplicando diseño centrado en el usuario y una arquitectura preparada para crecer.

Reservas claras

Visualiza turnos y organiza el uso de aulas sin perder trazabilidad.

Roles definidos

Separación de funciones para usuarios, administradores y responsables de gestión.

Gestión centralizada

Todo el proceso vive en una misma plataforma para reducir errores y tiempos muertos.
